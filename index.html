Import a score

Import an uncompressed MusicXML (.musicxml or .xml) score, or a Sonora JSON backup. These files are read in this browser and are not uploaded. Use Analyze for score images/PDFs or audio with the local model server.

OR ENTER A NOTE SEQUENCE

Use note names and durations in quarter-note beats, for example: C4:1 D4:0.5 E♭4:1.5. Imported notes go into the current score.
